# Friday — Hour One

> Open this file every Friday at the start of your first focused hour.
> The week ends with discipline, not a sprint.

## Step 1 — Shipped this week (10 min)

```text
[ ] open 02-product/release-notes.md — write a one-line entry per shipped item
[ ] open 06-memory/weekly-summary.md — fill the "Shipped" section for this week
[ ] open 02-product/PHASE-1B-EXECUTION-TRACKER.md — tick boxes for what landed
[ ] commit: "docs: friday wrap [week N]"
```

## Step 2 — Slipped this week (10 min)

For each Monday priority that didn't ship, write:

```text
Priority X: [name]
  Why slipped: [honest one-liner]
  Carry forward to next week: yes / no
  If yes, why is it MORE likely to ship next week?
  If no — was it actually a priority?
```

Append to 06-memory/weekly-summary.md.

## Step 3 — Decisions logged (5 min)

```text
[ ] any architectural / commercial / process decision this week?
[ ] add to 02-product/decision-log.md as a new ADR
[ ] commit
```

## Step 4 — Risks update (5 min)

```text
[ ] open 06-memory/risks.md
[ ] anything new this week? add it.
[ ] anything mitigated? annotate (don't delete).
[ ] any risk now red that was amber? escalate to Monday Priority 1.
```

## Step 5 — Learnings capture (10 min)

```text
[ ] open 06-memory/learnings.md
[ ] one or two L-NNN entries from the week
[ ] each entry has carry-forward (how this changes how I work)
[ ] commit
```

## Step 6 — OneOfZero commercial assets (10 min)

```text
[ ] anything proof-worthy this week? capture in oneofzero-os/05-memory/proof-log.md
    - a screenshot
    - a metric (admin time saved, batch imported, backup verified)
    - a quote from Midland
[ ] anything case-study-worthy? note in oneofzero-os/02-sales/midland-case-study.md
[ ] anything pricing-relevant? (if a request would have been Phase 2, capture
    in oneofzero-os/02-sales/commercial-strategy-pricing.md)
```

## Step 7 — Setup for Monday (5 min)

```text
[ ] open Monday's hour-one file
[ ] pre-write tentative top 3 for Monday
[ ] do NOT commit (you'll re-decide on Monday morning)
[ ] close laptop. Weekend protected.
```

## Total

55 minutes. The week ends documented and the OS holds.

If you ship code on Friday afternoon, you are violating the deployment runbook
(deploy on Tuesday or Wednesday).
