# OneOfZero OS — Weekly Operating Cadence

## Mon / Wed / Fri Rhythm

### Monday — Plan
- Top 3 priorities for the week
- Blocked tasks (what needs client input?)
- Open risks (what could derail this week?)
- Update `midland-os/06-memory/weekly-summary.md`

### Wednesday — Build Checkpoint
- What shipped since Monday?
- What is in progress?
- Any scope creep attempts this week?
- Update `midland-os/06-memory/weekly-summary.md`

### Friday — Wrap
- What shipped this week?
- What slipped and why?
- Decisions made this week
- Commercial notes (any scope requests, change requests, Midland conversations)
- Update:
  - `midland-os/06-memory/weekly-summary.md`
  - `midland-os/02-product/decision-log.md`
  - `midland-os/06-memory/risks.md`
  - `midland-os/06-memory/learnings.md`
  - Capture before/after proof if a milestone was hit

## Every Milestone
- Screenshot or log evidence
- Update CANONICAL-STATUS.md
- Update PHASE-1B-EXECUTION-TRACKER.md
- Commit with descriptive message
- Note Midland-facing value at this checkpoint

## The Anti-Drift Rule
At the start of every session:
1. Read CANONICAL-STATUS.md
2. Run `git status` + `npx tsc --noEmit`
3. Identify the single next action
4. Do only that — nothing else without explicit intent

## Solo Operator Mental Model
28–30 hrs/week. That is ~5–6 focused hours/day on work days.
Not 8 hours. Not agency hours. Real solo hours.
Plan accordingly. Do not commit to agency-pace timelines.
