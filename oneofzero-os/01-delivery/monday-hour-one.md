# Monday — Hour One

> Open this file every Monday at the start of your first focused hour.
> Do not check email until you've completed it.

## Step 1 — Status snapshot (5 min)

```text
[ ] open midland-os/00-core-context/CANONICAL-STATUS.md
[ ] update Date and "Day N" line
[ ] confirm execution slice
[ ] commit and push: "docs: monday status snapshot"
```

## Step 2 — Top 3 priorities (10 min)

Pick three. Write them in 06-memory/weekly-summary.md under this week's section.

```text
Priority 1: [must-ship outcome by Friday]
Priority 2: [must-ship outcome by Friday]
Priority 3: [must-ship outcome by Friday]

Each priority must be:
  - one sentence
  - testable (you'll know on Friday whether it shipped)
  - inside the current execution slice
  - not "make progress on X" — name the deliverable
```

## Step 3 — Open loops review (10 min)

```text
[ ] open 06-memory/open-loops.md
[ ] for every "Open — waiting on Midland":
      decide nudge / escalate / leave
      if nudge: send the nudge today
      if escalate: schedule call this week
[ ] for every "Open — waiting on Paul":
      schedule when you will close it this week
[ ] commit changes
```

## Step 4 — Risks check (5 min)

```text
[ ] open 06-memory/risks.md
[ ] any new risks since Friday? add them.
[ ] any risk now mitigated? mark mitigated, don't delete.
[ ] anything 🔴 red and not currently being worked on? escalate to Priority 1.
```

## Step 5 — Build plan for the day (10 min)

```text
[ ] open 02-product/PHASE-1B-EXECUTION-TRACKER.md
[ ] which Day N am I on?
[ ] what are the boxes to tick today?
[ ] what's blocking? (capture in open-loops.md)
[ ] one Claude Code / Codex task — name it before opening the editor
```

## Step 6 — Commercial check (5 min)

```text
[ ] any pending Midland decisions? (Option A vs B, Privacy Officer review, etc.)
[ ] any new lead conversation queued?
[ ] retainer health for the month — anything irregular?
[ ] any invoicing due this week?
```

## Step 7 — Email triage (10 min, ONLY now)

```text
[ ] Midland-related email
[ ] AWS / vendor email
[ ] OneOfZero invoicing / tax
[ ] anything else: defer to evening
```

## Total

55 minutes. You are now ready to do real work for the rest of the day.

If you skipped any step, the rest of the week is more likely to drift.
