# Offer Positioning

## The offer (sentence form)

> We build a Production Operations Portal that replaces your third-party ordering dependency, gives admin staff a real operating layer over the data, and comes with a documented operating system so your clinic isn't dependent on us forever.

## The offer (Hormozi Grand Slam frame)

```text
DREAM OUTCOME
  Clinic admins stop calling and emailing to manage CPAP supplies.
  Funded entitlement is visible. Data is exportable. Backups are real.
  We see exactly what happened, who did it, and when.

PERCEIVED LIKELIHOOD OF ACHIEVEMENT
  We have a working prototype.
  We have a 50–100 record import already running.
  We have HIPC-aligned audit + encryption + masking.
  We have demo accounts that show every flow end-to-end.

TIME DELAY
  Phase 1A demo                        2–3 weeks (already done)
  Phase 1B production go-live          ~8 weeks (June 30 target)
  Backup + export visibility            included in Phase 1B (Days 33–37)
  Retainer-driven improvements          monthly cadence

EFFORT & SACRIFICE
  Midland-side: ALTER export confirmation, Privacy Officer review, training session
  OneOfZero-side: full delivery + handover + documented operating layer
  No 24/7 SLA expectation. No employee-style availability.
```

## The offer stack (what's included in NZD 42k)

```text
1.  live production admin / patient portal foundation
2.  controlled import governance
3.  controlled real import of first 50–100 patient-style records
4.  admin patient list + drawer
5.  basic review visibility
6.  Admin Data Operations: Export + Backup + AWS State Visibility (v3.1)
7.  essential UI/UX polish

9.  support model + retainer boundaries
10. Midland OS v1 documentation layer

```

## The retainer (NZD 2,300/month)

```text
- maintenance + minor fixes
- monthly improvement review (1 hour)
- AWS / hosting monitoring + adjustments
- Cognito user pool admin assistance
- support questions (reasonable volume)
- audit log spot-checks
- backup verification
- release oversight
- one new staff training session per year
```

```text
- inventory + supplier integration (Phase 4)
- patient invitation automation (Phase 2)
- automated patient email (Phase 2)

```

## Risk-reversal language for proposals

```text
"If we miss Phase 1B go-live by more than 2 weeks for reasons within our
 control, the deposit milestone is held until you're satisfied with the
 closeout."

"If you decide after Phase 1B handover that you don't want to continue
 with the retainer, you keep the portal and Midland OS docs at no
 ongoing fee. AWS hosting becomes your responsibility."

"All exports are NHI-excluded by default. Backup discipline is real, not
 a checkbox. You can verify both before signing the final acceptance."
```

## Why Option B is the honest call (Admin Data Operations add-on)

```text
- Backup is a baseline safety obligation, not a feature
- Export visibility is what makes the portal usable
- This would otherwise be Phase 2 scope — bringing it forward is real value
- NZD 2,500–3,500 add-on raises anchor to NZD 44,500–45,500
- Removes ambiguity in scope conversations later
- Honest pricing builds trust for Phase 2+ negotiations
```
