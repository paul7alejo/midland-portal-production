# Strategy Prompts

> Drop-in prompts for business / pricing / scope sessions.

## Pricing review

```text
Review this pricing for [clinic name]. Anchor: NZD [X] build, NZD [Y] retainer.
Is this appropriately priced for the value delivered? What would Hormozi say?
Reference: oneofzero-os/02-sales/commercial-strategy-pricing.md
```

## Scope creep check

```text
The client asked for [feature]. Is this Phase 1B scope or a change request?
If change request, quote it separately. If it should be absorbed, explain why.
Reference: midland-os/02-product/mvp-rules.md
```

## Lead magnet review

```text
Review this lead magnet idea: [description].
Does it give away the secrets and sell the implementation?
Will it attract the right clinic archetype?
Reference: oneofzero-os/00-positioning/target-clients.md
```

## Monthly review prep

```text
Prepare the agenda for this month's improvement review with [clinic].
Include: tickets summary, uptime, billing, backup status, feedback, proposed improvements.
Reference: midland-os/04-sops/support-model.md
```
