# OneOfZero Learnings

## L-001 — Demo beats deck
Phase 1A prototype closed the conversation faster than any proposal document.

## L-002 — Document the operating layer or you ARE the operating layer
Without SOPs, Midland calls Paul for everything. With SOPs, Paul is the safety net, not the bottleneck.

## L-003 — Sell the package, not the feature
"Biomedical Spreadsheet-to-Admin Portal Operations Package" anchors higher than "CSV import tool."

## L-004 — Backup is not a feature, it's table stakes
Three-layer backup discipline should be in every Phase 1, not deferred to Phase 2.

## L-005 — NHI default-exclude is the only safe export rule
Every export drifts toward including NHI. Make exclusion the default; inclusion the exception with friction.

## L-006 — The retainer is the prize
Year 1 retainer (NZD 27.6k) is 66% of build revenue (NZD 42k). By Year 2 retainer exceeds build. Protect it.
