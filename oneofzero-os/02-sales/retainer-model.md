# OneOfZero OS — Retainer Model

## What the Retainer Covers (NZD 2,300/month incl GST)

| Included | Not Included |
|---|---|
| AWS cost monitoring + alerting | New feature builds |
| Security patch reviews | Schema migrations |
| SOP updates (minor) | New integrations |
| 2 minor improvements/month | Phase 2+ work |
| CloudWatch alarm response | Staff training beyond onboarding |
| Bug fixes (portal defects) | ALTER format changes (bespoke) |
| Monthly check-in call | On-call 24/7 response |

## Retainer Boundaries
- Response time: next business day for non-critical issues
- Critical issues (portal down, data breach risk): same day
- "Minor improvement" = ≤4 hours of work. Larger = change request.
- Retainer does NOT mean unlimited availability

## Retainer Starts
Retainer billing begins on go-live date (target: July 1, 2026).
Phase 1B build cost (NZD 42k) is separate — invoiced per milestone:
- Milestone 1: Contract signed + deposit (30% = ~NZD 12,600)
- Milestone 2: Staging live + Midland review (40% = ~NZD 16,800)
- Milestone 3: Production go-live (30% = ~NZD 12,600)

## Future Retainer Scaling
- Month 12: Phase 2 activation. Retainer may increase to NZD 2,800–3,200/month.
- Year 2: Multi-clinic. Platform retainer model — per-clinic fee stacked on base.

## Rule of 100 for Retainer
If a request comes in during the retainer month:
1. ≤4 hours — handle in current month
2. >4 hours — raise change request, quote separately
3. Never say "I'll just fit it in" — that's how retainers become unpaid employment
