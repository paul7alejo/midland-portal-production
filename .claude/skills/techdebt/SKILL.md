# /techdebt
Triage tech debt items into the backlog.
## Format
```
TD-XXX | severity (low/med/high) | description | phase target | effort (S/M/L)
```
## Rules
- Log in midland-os/02-product/feature-backlog.md under appropriate phase
- Do not fix inline — document and move on
- High severity = address before go-live
- Med severity = address in retainer period
- Low severity = Phase 2+
