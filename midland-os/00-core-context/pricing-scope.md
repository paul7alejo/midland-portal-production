## Phase 1 INCLUDES

```text
1.  live production admin/patient portal foundation

3.  controlled real import of first 50–100 patient-style records
4.  admin patient list + detail / drawer
5.  basic review visibility
6.  Admin Data Operations: Export + Backup + AWS State Visibility (v3.1)
7.  essential UI/UX polish
8.  SOPs, onboarding, handover
9.  support model
```

## Phase 1 EXCLUDES (frozen until override)

```text
- full ecommerce checkout / Stripe / payments
- shop, inventory, suppliers, fulfilment
- automated Biomedical/ALTER sync (one-way out only)
- mobile app, PWA, native build
- patient invitation automation
- automated patient email
- advanced audit dashboard
- SSO / Azure AD federation
- Terraform / IaC (Months 5–6, post-launch)
- broad AI chatbot or agent features
- legal / compliance certification responsibility
- clinical responsibility
```
