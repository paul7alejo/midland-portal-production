# Admin Review SOP

## Purpose

This SOP describes how staff review imported patients after a controlled import.

## Steps

1. Open `/admin/patients`.
2. Search for the imported patient by name or MSID.
3. Locate records marked `Pending review`.
4. Open the drawer using `View` or `Review record`.

## Patient Fields

Review:

- Name
- MSID
- Date of birth
- Phone
- Email
- Address

## Device Fields

Review:

- Machine brand
- Machine model
- Machine serial number
- Setup date
- Device ID

## Mask Fields

Review when present:

- Mask brand
- Mask model
- Mask size

If no mask was imported, the drawer will show `No mask record imported`.

## Funding Source

Review the imported funding source and confirm whether it is appropriate for the patient record.

## Problems and Escalation

For now, record problems outside the system using the agreed Midland operational process.

Escalate unclear, clinical, identity, funding, or data quality issues to the nominated Midland owner. Do not resolve clinical or legal questions inside the platform without Midland approval.
