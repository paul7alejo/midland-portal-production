# Support Model

## Included Support

Recommended included support after go-live:

- Bug fixes for agreed production workflows.
- Minor operational guidance for admin users.
- Deployment checks for agreed releases.
- Import support by agreed batch.
- Triage of production issues within agreed support windows.
- Clarification of documented workflows and SOPs.

## Excluded Support

Unless separately agreed, support excludes:

- Unlimited changes or open-ended feature development.
- Clinical decisions.
- Legal, privacy, or compliance sign-off.
- Unlimited spreadsheet formats.
- Emergency SLA or after-hours response.
- Data correction work that requires clinical or operational judgement.
- Patient communications or clinical follow-up.

## Recommendation

After go-live, Midland should move to a monthly support or retainer model. The retainer should define response windows, release cadence, import support expectations, escalation contacts, and boundaries between technical support and Midland operational ownership.
